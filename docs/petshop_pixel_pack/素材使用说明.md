# 素材包使用说明

这份包提供本版固定角色阵容的静态美术素材、开场与创建流程场景、Cursor 升级任务和主线设计。PNG 是生成后的原始文件，未经过额外缩放、抠图或像素重绘。

## 包内内容

- `assets/characters/`：默认店主、三名候选员工及十二名街坊，共七张透明图集。
- `assets/pets/`：六只店内宠物与五只来访动物，共四张透明图集。
- `assets/customization/`：一个基础人偶和一张十六部件图集，共两张透明 PNG。
- `assets/scenes/`：六种装修合集、四种店址合集、开场街景，共三张完整背景 PNG。
- `asset-manifest.json`：十六张图片尺寸、SHA-256、语义 id 与 205 个显示区域。
- `人物宠物设定.md`：角色姓名、外形、性格、关系及图集对应。
- `Cursor_像素版升级指令.md`：本次升级的完整开发任务，以此作为创建流程的最新要求。
- `主线剧情_八章版.md`：八章、33 节点的剧情大纲和实施规则。
- `宠物店游戏方案_Cursor开发版.md`：经营、广告、剧情和本次创建流程整合版。
- `prompts.json`：本批素材的原始生成提示词和输出记录，方便延续角色风格。

这是图集交付，不是 205 个独立 PNG。可在引擎内根据矩形直接显示，避免反复下载相同的大图。205 个区域包括：108 个人物视图/表情、69 个动物视图/表情、17 个基础人偶与服装区域、11 个背景区域。

## 推荐导入顺序

1. 把整个文件夹放进现有 Cursor 项目，先让 Cursor 阅读升级指令。
2. 将 `assets/` 中图片复制到该项目实际静态资源目录，保持英文文件名。
3. 根据 manifest 建立统一素材注册表，不在组件中手填多个重复 URL。
4. 先完成一套角色和一个背景的帧显示，再接完整创建流程。
5. 调整换装部件位置和六套房间的角色落脚点，逐项验收。

示例：`frames['dahuang.happy']` 指向 `pet_dahuang` 图集中的开心头像区域；`frames['interior.nordic_nature']` 指向北欧场景；`frames['hair.chestnut_bob']` 指向栗色发型部件。

角色立绘透明处保留透明度。看到部分图片查看器显示深底，不代表背景已被画死；请在棋盘格或浅色底上检查 alpha。场景图是 RGB，不透明，适合作为底层。

## 必须知道的制作边界

这些是精致像素插画静态资源，不是已完成的游戏客户端或已绑定的动画工程。

- 立绘/三视/表情可以用于对话、档案、选人及静态场景。
- 本包没有走路、跑跳、尾巴摇动等逐帧动画，不把三视串起来冒充动画。
- 基础人偶和服装部件来自不同画布，尚未以同一骨架标定；Cursor 要完成每件部件的缩放、定位、遮挡适配。
- 当前四类各四件衣装支持正面组合；256 套侧面/背面组合不是本包的交付范围。
- 主场景六种装修已分别绘制；家具是背景组成部分，不是已拆开的可移动模块。
- 开场提供一张全景，镜头运动在代码中实现。图片本身不包含真实视频或独立前中后景。
- 纪念合照可先用现有角色与照片边框组合；专门的剧情 CG、全套物品图标、商业 logo 和所有音效尚未制作。
- 表情和视图已按身份检查；manifest 中矩形按透明区域整理，仍标注 `reviewRequired`，需要在实际显示尺寸复核边缘。像素画内的少量细节和不同视角比例差异，后续动画制作时需统一。

## 开场与店址的关系

开场公共街景出现在玩家选址之前，负责标题页演出。选址之后保存真实 locationId；地址预览显示对应外景，室内显示独立 styleId。不能因为开场是老街风格，就强制玩家选择老城区。

## 性能和清晰度

原始 PNG 合计约 34 MiB。首屏只预载开场与当前必需的素材，其他图集按页面分批加载，避免手机首次等待全部资源。上线压缩应以实际观感检查为前提，保留原图备份。不要直接把所有大图转成内联 base64 放入主 JavaScript 包。

中文标题和 UI 文字用真实文本叠加；角色与背景使用图片。像素素材保持清晰边缘，正常正文不套像素缩放。manifest 中尺寸来自本批实际文件，不能照着提示词中原计划尺寸写死。

## 内容版本优先级

本次创建流程优先使用 `Cursor_像素版升级指令.md`：开场 → 标题 → 命名 → 六装修 → 四选址 → 店主独立换装 → 三选二店员。旧版本「直接命名、随机地址、身高、固定三员工、同场景换颜色」均已被替换。

主线和经营数据仍遵守每日五行动、每事件三个选项、关门日报、现实日常的核心规则。广告只保留原有明确自选的位置，不进入创建流程。
