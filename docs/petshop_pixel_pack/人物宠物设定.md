# 人物与宠物美术设定

统一为现实小镇背景的精致 Q 版像素插画。固定角色的外貌、毛色和服装标志保持一致；店主允许玩家搭配。动物的表情图用于 UI 情绪表达，不表示它们会说人话。年龄为故事设定，动物不随离线时间自动衰老。

本包共 16 位人物和 11 只动物。所有角色都有正面、左侧面、背面及表情头像。人物表情图是头肩像，可直接作为对话半身立绘，也可在头像框中显示头部。默认店主、三名员工和大黄各有 6 个表情：日常、开心、担忧、惊讶、认真、困倦。其余角色各有日常、开心、担忧 3 个表情。表情命名详见 manifest。
