# 部署说明

这个项目是 Vite 静态页面。生产环境使用 `npm run build` 生成的 `dist/`，不要把 TypeScript 源文件当成页面上传。

当前仓库是 `AnqiiHuang/chongwu`。如果部署到 `https://anqiihuang.github.io/chongwu/`，`vite.config.ts` 里的 `base` 必须是 `/chongwu/`。部署到域名根目录时，把 `base` 改成 `'/'`，再重新构建。

图片、图标和入口都从 `public/` 与构建结果里读取，会跟着 `base` 走。游戏使用页面内部切换，没有需要服务器回退的前端路由。

建议步骤：

1. `npm test`
2. `npm run build`
3. `npm run preview`，打开打印出来的 `/chongwu/` 地址，确认能进开场并在刷新后继续
4. 把 `dist/` 目录交给静态托管。不要上传仓库根目录或 `src/`

GitHub Pages 由 `.github/workflows/deploy.yml` 发布。它在 `main` 上安装依赖、执行 `npm run build`，再用官方 Pages Action 发布 `./dist`。仓库里没有第二份部署工作流。

后台要这样设置：仓库 Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。不要选 “Deploy from a branch”，尤其不要把 `main` 的根目录或 `/docs` 当作发布内容；那样线上会继续使用带 `/src/main.tsx` 的开发入口。

推送到 `main` 后，在 Actions 里等 “Deploy to GitHub Pages” 成功。站点地址仍是 `https://anqiihuang.github.io/chongwu/`。页面上的广告测试按钮不会产生广告收入。
