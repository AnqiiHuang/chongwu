# 震惊！我开了一家宠物店

手机竖屏的宠物店经营游戏。现在能玩到第一个月：三条社区故事、六只宠物、员工培训、月报和二星。

## 本地运行

```bash
npm install
npm run dev
```

开发地址是 [http://localhost:5173/chongwu/](http://localhost:5173/chongwu/)。仓库页面路径是 `/chongwu/`，所以本地也带这个前缀。

```bash
npm test
npm run build
npm run preview
```

生产预览同样在 `/chongwu/` 下。部署说明见 `docs/部署说明.md`。

## 这一阶段能玩什么

给宠物店起名，选一种装修，揭晓四个地址中的一个，确认店主和三位员工。每天 5 次行动，每个事件 3 个选项，确认选项才扣 1 点。第五次之后是 22:30 的日报，点「开启明天」才进入下一天。进度自动存在浏览器里，也可以导出。

开张日之后，花店、大黄和乌云的故事会一天接一段。芝麻和糯米住在各自的区域。Lv.5 可以培训员工。月底能看月报，二星在综合分、幸福和花店故事都达到后点亮。正式插画和真实广告还没做。
